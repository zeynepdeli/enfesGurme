# Antep Peynirim - E-Ticaret Platformu

## 📁 Proje Yapısı
```
antep-peynirim-monorepo/
├── frontend/     → Next.js 16 (React)
├── backend/      → Node.js + Express + TypeScript
└── README.md
```

## 🚀 Başlatma

### Backend
```bash
cd backend
pnpm install
pnpm dev
```

### Frontend
```bash
cd frontend
pnpm install
pnpm dev
```

## 🔗 URL'ler

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API Docs: http://localhost:8000/health

## 🛠️ Teknolojiler

### Backend
- Node.js + Express
- TypeScript
- Prisma ORM
- PostgreSQL (Supabase)
- JWT Authentication

### Frontend
- Next.js 16
- React
- TypeScript
- Tailwind CSS
